Privacidad TripLogix

Aviso de privacidad

Este aviso describe cómo TripLogix trata datos personales dentro de su ecosistema de transporte: Torre de Control / Despachador, TripLogix Conductor y TripLogix Cliente.

Última actualización: 22 de septiembre de 2026 Aplica a las 3 aplicaciones TripLogix

1. Responsable y alcance

TripLogix es responsable del tratamiento de los datos personales utilizados para operar sus servicios de planeación, despacho, monitoreo, seguimiento, comunicación y trazabilidad de transporte corporativo. Este aviso aplica a la plataforma web de despacho y a las aplicaciones TripLogix Conductor y TripLogix Cliente.

Para ejercer derechos de privacidad o solicitar la eliminación de datos, puedes utilizar el formulario de Solicitud de eliminación de datos.

2. Datos que podemos tratar

AplicaciónDatos relacionados con su operación
Torre de Control / DespachadorDatos de identificación y contacto de usuarios, pasajeros y conductores; asignaciones; viajes; horarios; rutas; puntos de encuentro; estados de servicio; historial; incidencias; evidencias y registros de auditoría.
TripLogix ConductorNombre y datos de contacto; información del servicio asignado; ubicación del dispositivo durante la operación cuando el permiso correspondiente está activo; avance de ruta; marcas de tiempo; abordajes; evidencias o fotografías operativas; comunicaciones y token del dispositivo para notificaciones.
TripLogix ClienteNombre y datos de contacto; servicios y viajes asociados; conductor y unidad asignados; información de ruta y estado del viaje; respuestas y alertas dentro de la app; comunicaciones relacionadas con el servicio y token del dispositivo para notificaciones.

El tratamiento concreto puede variar según las funciones habilitadas para cada operación o cliente corporativo.

3. Finalidades

  • Crear, administrar y operar perfiles de usuario vinculados a TripLogix.
  • Planear, asignar, despachar y dar seguimiento a servicios de transporte.
  • Mostrar información de rutas, horarios, unidades, conductores y pasajeros según el rol autorizado.
  • Permitir monitoreo operativo y trazabilidad de recorridos.
  • Gestionar carpooling, puntos de encuentro, abordajes, incidencias y evidencias.
  • Enviar notificaciones sobre asignaciones, inicio, proximidad, cambios y finalización de servicios.
  • Habilitar comunicaciones relacionadas con la operación entre participantes autorizados.
  • Mantener historial y registros de auditoría para seguridad, soporte y mejora operativa.
  • Atender solicitudes de soporte, privacidad y eliminación de información.

4. Permisos y datos sensibles de operación

Ubicación

TripLogix Conductor puede utilizar la ubicación del dispositivo durante un servicio para permitir el seguimiento operativo de la unidad y conservar trazabilidad del recorrido. El acceso depende de los permisos otorgados en el dispositivo y de las funciones habilitadas.

Cámara, fotografías y evidencias

Cuando una función de evidencia lo requiera, la aplicación puede permitir capturar o adjuntar fotografías relacionadas con el servicio. Estas evidencias se utilizan únicamente dentro del contexto operativo correspondiente.

Notificaciones

TripLogix Conductor y TripLogix Cliente pueden registrar un token técnico del dispositivo para enviar notificaciones relacionadas con los servicios. El usuario puede administrar los permisos de notificación desde la configuración de su dispositivo.

5. Infraestructura y proveedores tecnológicos

Las aplicaciones TripLogix utilizan servicios de Google Firebase para almacenamiento y sincronización de información operativa y, cuando corresponde, Firebase Cloud Messaging para notificaciones. También pueden intervenir servicios de mapas, navegación o comunicación necesarios para ejecutar las funciones solicitadas por el usuario.

Los proveedores tecnológicos actúan de acuerdo con sus propios términos y políticas aplicables. TripLogix limita el uso de la información a los fines necesarios para prestar y proteger el servicio.

6. Conservación y eliminación

Los datos se conservan mientras sean necesarios para prestar el servicio, mantener continuidad operativa, atender incidencias, cumplir obligaciones aplicables y conservar registros legítimos de seguridad o auditoría. Cuando una persona solicita la eliminación de su cuenta o información, TripLogix revisará los datos asociados y eliminará aquellos que deban suprimirse, salvo los que exista una razón legal, contractual, de seguridad o prevención de fraude para conservar.

7. Derechos de las personas titulares

Las personas titulares pueden solicitar acceso, rectificación, cancelación u oposición al tratamiento de sus datos, así como revocar consentimientos cuando resulte aplicable. Para iniciar una solicitud de eliminación, se ofrece un formulario web accesible sin necesidad de volver a instalar ninguna aplicación.

Solicitar eliminación de datos → Volver a TripLogix

8. Seguridad y cambios a este aviso

TripLogix aplica medidas administrativas y técnicas razonables para limitar accesos no autorizados y proteger la información dentro de su operación. Este aviso puede actualizarse cuando cambien las funciones, los proveedores, las obligaciones aplicables o las prácticas de tratamiento. La versión vigente se publicará en esta misma página con su fecha de actualización.
